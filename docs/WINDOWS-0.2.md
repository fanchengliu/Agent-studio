# Agent Studio 0.2 · Windows 本机版

当前范围：Windows 本机完整协作客户端。参考 MAO 中文主页与官方桌面文档的工作方式，以独立源码实现；收费、试用、激活、云账号，以及 SSH / 手机 / Mac 设备功能不进入本次交付范围。

参考入口：https://trymao.dev/zh 和 https://trymao.dev/docs 。本文件记录本项目实现，不把官网描述当成测试证据。

## 界面与画布

- 默认浅色网格、紧凑白色节点、圆角画布、细虚线连接、右侧悬浮工具栏。
- 原生 Windows 标题栏控制；可收起导航栏；详情面板按需打开。
- 平移、缩放、当前百分比、100% 重置、适应全部、小地图、节点聚焦。
- 多选、拖动、批量位置保存、网格吸附、箭头微调、锁定、右键菜单。
- 画布结构变更的撤销 / 重做；撤销前检查并发变化，保留无关会话信息。
- 区域框、成员分组、分组拖动、文字标注、自由画笔。
- 九个视图书签，Alt+数字跳转，Ctrl+Alt+数字保存。

## 协作与账号

- 独立 Agent、角色和模型；角色库；自定义团队模板。
- 有向流程按依赖传递真实结果；选中成员广播；连接授权的异步派活与结果查询。
- 跨本机工作台连接；主控创建队友；MCP 协作桥。
- 会话历史、原会话继续、任务停止、失败重试、并发限制、任务时限。
- Codex / Claude Code 独立账号配置目录；其他工具沿用自己的登录管理。
- Codex、Claude Code、Grok、Cursor、Antigravity、OpenCode、Gemini CLI 和自定义 CLI 入口；DeepSeek 兼容 API。
- 原生 ConPTY 终端；权限询问和执行过程；关闭窗口后可选择托盘继续运行。

## 项目与交付

- 本地项目与虚拟分组、文件浏览/编辑、附件上传。
- 共享 Markdown 便签、笔记本、便签释放；共享内容冲突检查。
- Git 状态、统一/并排差异、暂存/取消暂存、提交、近期历史。
- 独立 Git worktree、合并、归档、恢复；未提交改动保护。
- 浏览器窗口、页面快照、点击、输入、截图；连接后的 Agent 可操作页面。
- 间隔、每日、每周、单次任务；忙碌跳过；默认不自动启用。
- 手动备份、可选每日自动备份、恢复、任务结果导出；自动备份保留 14 天，手动备份不自动清理。
- 浅色/深色/跟随系统、减少动态、可选系统通知。

## 实现与验证的区别

本机接口、状态机、进程协议、画布、文件与 Git 检查使用真实程序或明确的测试协议子进程。测试不会消耗模型额度。

各家实际模型的额度、账号授权、响应质量和完整任务结果仍需要在用户的登录环境下运行验证。协议测试不能代替这一步。Windows 上未安装的工具需要在连接设置中安装/指定路径。

窗口和流程采用自己的实现，不复制 MAO 的原生 GPUI 渲染内核。更新采用本地便携包替换，没有在线收费、激活或发布服务。独立账号配置目录目前专门适配 Codex 和 Claude Code；未声称每家私有账号协议均已实测。

## 启动

便携目录中的 `Agent Studio.exe` 是启动入口。源码开发使用 `start.cmd`。升级前退出旧版，用户运行数据保留在原来的 userData 目录。
